# Torn userscripts

Torn browser userscripts by **DarrylPhilbin**, prepared for the `vexiumlabs/torn-scripts` GitHub repository. Each script folder contains the installable source and a short README.

## Scripts

| Script | Description | API key |
| --- | --- | --- |
| [Keno Randomizer](keno-randomizer/README.md) | Randomly select one to ten numbers on Torn's Keno board. | None |
| [Passive Income](passive-income/README.md) | Estimate recurring daily income, compare stock benefit purchases, and budget training costs. | Full Access |
| [Travel Counter](travel-counter/README.md) | Display the API key owner's lifetime visits to all eleven Torn travel destinations. | Limited access |
| [Calendar Local Time](calendar-local-time/README.md) | Add local start and end times beneath Torn's calendar event times. | None |
| [Chain Watcher](chain-watcher/README.md) | Desktop notifications at one minute and 30 seconds remaining on your faction chain. | None |
| [Halloween Helper](halloween-helper/README.md) | Yearly treat receipts, pinned basket upgrades, and a movable Halloween target list. | Full Access |
| [RR Odds](rr-odds/README.md) | Display single, double, and triple shot risks from the visible Russian Roulette game. | None |

## Installation

Open the desired script folder and its `.user.js` file. Use GitHub's **Raw** view to copy the complete source into your userscript manager, save, enable, and reload Torn. Each folder documents setup and supported environments. Update an existing installation in place to preserve settings and avoid duplicates.

Enter API keys through the script settings. Settings stay on your browser/device; TornPDA support and storage are described in the individual guides.
