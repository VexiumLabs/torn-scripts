# Torn Passive Income

Estimate recurring daily income, compare stock benefit purchases, and budget training costs.

**Author:** DarrylPhilbin  
**Version:** 1.5.2  
**Environment:** Tampermonkey or TornPDA  
**API key:** Full Access

## Install and use

1. Open [torn-passive-income.user.js](torn-passive-income.user.js) and use GitHub's **Raw** view to copy the complete source into a new userscript.
2. Save, enable, and reload Torn. To update, replace the existing installed copy to preserve settings and avoid duplicates.
3. Click Income, open Settings, enter your own key, and Save & refresh. Daily equivalents are estimates, not daily payouts.

See [the detailed guide](GUIDE.md) for configuration, storage, limitations, and historical development notes.
