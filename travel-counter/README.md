# Torn Travel Counter

Display the API key owner's lifetime visits to all eleven Torn travel destinations.

**Author:** DarrylPhilbin  
**Version:** 1.2.0  
**Environment:** Tampermonkey or TornPDA  
**API key:** Limited access

## Install and use

1. Open [torn-travel-counter.user.js](torn-travel-counter.user.js) and use GitHub's **Raw** view to copy the complete source into a new userscript.
2. Save, enable, and reload Torn. To update, replace the existing installed copy to preserve settings and avoid duplicates.
3. Open the Travel Agency and enter your key using API key in the My country visits panel. Public Only keys cannot read these statistics.

See [the detailed guide](GUIDE.md) for configuration, storage, limitations, and historical development notes.
