# Torn Keno Randomizer

Randomly select one to ten numbers on Torn's Keno board.

**Author:** DarrylPhilbin  
**Version:** 1.0.0  
**Environment:** Tampermonkey  
**API key:** None

## Install and use

1. Open [torn-keno-randomizer.user.js](torn-keno-randomizer.user.js) and use GitHub's **Raw** view to copy the complete source into a new userscript.
2. Save, enable, and reload Torn. To update, replace the existing installed copy to preserve settings and avoid duplicates.
3. Open Keno, choose Picks, and click Randomize. Saves your selection count in localStorage. It changes selections only and does not place bets or improve the odds.

No API key, external libraries, or network requests are required. The source retains its reference credit for the board selectors.
